# 任务、记忆与文件能力规格

## 目标

为每个工作区提供可恢复的定时任务、可审计的工作区记忆、受路径与大小限制的文件操作，以及可管理的终端会话。所有状态必须能够在服务重启后解释清楚，执行结果和通知结果必须分开记录。

## 任务

- 支持一次性、固定间隔和五字段 Cron；固定间隔和 Cron 的最小频率为 60 秒。
- 任务定义保存工作区、执行类型、提示词或脚本、上下文模式、下一次执行时间和状态。
- 每次执行拥有稳定的运行 ID、定义快照、尝试次数、开始/结束时间、耗时、结果、错误、租约和通知状态。
- 同一任务的运行按任务串行；不同任务可以并行。到期的周期任务在服务离线期间记为 `missed` 并推进游标；到期的一次性任务补建执行记录。
- 手动运行使用任务 ID 与幂等键生成稳定运行记录。HTTP、页面和其他入口共享同一持久化幂等约束。
- 智能体任务复用 Pi Runner 的会话串行和流式事件能力；隔离任务使用独立会话，工作区任务使用工作区会话。
- 脚本任务仅允许管理员在本地 Host 工作区执行，并受执行超时限制。
- 执行失败可以进行有界指数退避重试；通知失败只能重试通知，不重新执行任务。
- 任务支持暂停、恢复、编辑、停止和软删除；停止操作必须持久化，防止迟到的执行结果覆盖终态。

## 记忆

- 记忆类型为事实、决定、经验和待跟进事项。
- 记忆包含标题、内容、来源、创建/更新时间和单调递增版本号；每次修改保留版本记录。
- 读取、修改和搜索都按工作区隔离，并复用现有登录用户授权。
- 修改必须带期望版本号；版本不一致返回冲突，不覆盖他人的更新。
- 搜索只返回当前工作区的未删除记忆，支持标题、内容、类型和来源匹配。

## 文件与终端

- 文件浏览、上传、下载、文本读取和删除都限制在工作区根目录内，拒绝路径遍历与越界符号链接。
- 上传和文本读取有明确大小上限；纯文本格式直接读取，常见文档格式在外部提取器可用时提取，否则返回可解释的“不支持”结果。
- 终端会话记录所有者、工作区、状态和最近输出；输入、输出、关闭和断线清理必须经过所有权校验。
- 当前运行时优先使用真实 PTY；不可用时保留已有的子进程流降级模式，并向调用方明确标记降级状态。

## 验收

- 覆盖调度计算、重启恢复、手动幂等、任务串行、执行失败重试、通知单独重试和 abandoned 租约恢复。
- 覆盖记忆版本冲突、工作区权限、搜索和版本历史。
- 覆盖文件路径越界、符号链接、文件大小/类型限制和终端会话所有权。
- 完成后运行类型检查、全量测试、构建和差异检查，并逐条对照本规格复核。

## 明确不做

不实现计费、容器镜像和新的 IM 渠道；不把本地子进程流包装成完整的容器终端；不引入结构化文件编辑工具或声称工具集与参考项目完全一致。
